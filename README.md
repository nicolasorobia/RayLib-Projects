## Overview

This repository is a collection of small video games built with [raylib](https://www.raylib.com/), created to apply my understanding of C++ in a more fun and interactive way. Each project is an opportunity to practice core programming concepts — game loops, state management, collision detection, and input handling — through hands-on game development.

## Projects

- **Pong** — a recreation of the classic two-paddle arcade game.
- **Snake** — the classic grid-based game of growing a snake while avoiding collisions.

## Structure

Each folder contains a complete, self-contained game that anyone is welcome to copy into the IDE of their choice to run, test, and edit themselves.

Every project uses a `CMakeLists.txt` with raylib already integrated, so there is no need to install raylib separately on your machine. Cloning the project and building with CMake is all that is required to get a game running.

## Getting Started

1. Clone the repository.
2. Navigate into the folder of the game you want to run.
3. Build the project using CMake.
4. Run the generated executable.
